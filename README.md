# Decision & Focus Hub

SaaS combining decision models and productivity methods.

## Features

- Proven decision frameworks
- Focus dashboard

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/decision-spark-desk.git
cd decision-spark-desk
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
